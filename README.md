# NUverse Laguna

NUverse Laguna is a campus-exclusive web application designed specifically for the students, faculty, and staff of National University Laguna. The platform serves as a centralized digital ecosystem that combines campus utilities, student interaction, marketplace functionality, merchandise reservation, and engagement features into one modern and organized system.

The project was created to improve the overall campus experience by providing a dedicated platform where students can access important campus-related services and interact with the NU Laguna community more conveniently.

## Features

### Authentication System

* Secure login and registration
* Exclusive access for NU Laguna email accounts
* Role-based access for students and administrators

### Marketplace System

* Campus-exclusive buying and selling platform
* Product listings with images, descriptions, and pricing
* Search and filtering functionality
* Seller and buyer interaction features

### Bulldog Exchange System

* Official NU merchandise inventory viewing
* Real-time stock availability
* Reservation system with expiration handling
* Product variants for sizes and colors

### User Profiles

* Personalized student profiles
* Profile customization
* Follow and privacy features

### Bulldog Chibi System

* Customizable Bulldog companion
* XP and achievement system
* Cosmetic unlockables and interactions

### Campus Event System

* Event announcements and listings
* RSVP and event interaction features
* Organization and campus activity management

### Lost and Found System

* Lost item reporting
* Found item submissions
* Item search and status tracking

### Suggestions and Feedback System

* User-submitted suggestions
* Community feedback functionality
* Improvement and issue reporting

### Emergency Announcement System

* Campus-wide emergency notifications
* Important announcements and advisories

### NUIS Integration

* Quick access to the official university portal

## User Interface

NUverse Laguna features a modern and responsive user interface with:

* Light Mode and Dark Mode support
* Smooth animations and transitions
* Mobile-friendly responsive design
* Organized and student-centered layouts

## Purpose

The platform was developed to address common campus-related problems such as:

* Lack of centralized student services
* Difficulty checking merchandise availability
* Limited student interaction platforms
* Unsafe external student marketplace transactions
* Scattered campus information

NUverse Laguna focuses on practicality, usability, maintainability, and production-ready design while providing an engaging digital experience for the NU Laguna community.
